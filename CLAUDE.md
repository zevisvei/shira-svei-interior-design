# Shira Svei Interior Design website

Static marketing site for an interior design studio that helps American buyers of new-build (off-plan) apartments in Israel. Live at https://zevisvei.github.io/shira-svei-interior-design/.

Read [PRODUCT.md](PRODUCT.md) for the business and voice, and [DESIGN.md](DESIGN.md) for the visual system before changing any page.

## Layout

- `build.py` generates every HTML page in `site/` from one shared header, footer and set of helpers. **Never hand-edit `site/*.html` or `site/projects/*.html`**: the next build overwrites them. Edit the page bodies in `build.py`.
- `site/css/site.css`, `site/js/site.js` and `site/js/hero3d.js` are hand-written and edited directly.
- `site/vendor/` holds pinned local copies of three.js 0.170.0 and GSAP 3.12.5 (+ ScrollTrigger). They load on the homepage only. Do not switch them to a CDN.
- `site/img/` holds every image, `site/film.mp4` the film. All assets are local. The only external requests are Google Fonts and, when configured, Google Analytics. Nothing may depend on the old `*.chatgpt.site` prototype.
- `site/sitemap.xml` and `site/robots.txt` are generated by `build.py`.

## Commands

```bash
python3 build.py                                   # regenerate all pages, sitemap, robots
cd site && python3 -m http.server 8765             # preview at http://127.0.0.1:8765/
```

There are no dependencies and no package manager.

## Config (top of build.py)

- `SITE_URL`: live address, no trailing slash. Drives canonical URLs, `og:url`, `og:image`, sitemap.
- `GA_ID`: GA4 measurement ID. Empty means no tag. The contact form fires `generate_lead`.
- `GSC_VERIFICATION`: Search Console HTML-tag token. Empty means no meta tag.

## Deploy

Pushing to `main` deploys `site/` to GitHub Pages via `.github/workflows/pages.yml`. Rebuild and commit the generated files before pushing.

## Working rules

- Site copy is English (the audience is American). The site owner talks to Claude in Hebrew: reply in Hebrew.
- The homepage hero is a scroll-driven three.js scene (see DESIGN.md). Test it at several scroll positions, with `prefers-reduced-motion: reduce` (must fall back to the photo hero), and at 390px.
- After any visual change, check the rendered pages at 1366px and 390px wide (Playwright screenshots). Confirm no horizontal scroll and that the comparison sliders, lightbox, mobile menu and contact form still work.
- Run the `audit-ai-design-slop` skill after larger design changes.
- Keep contrast at WCAG AA, visible focus rings, 44px tap targets, and `prefers-reduced-motion` support.
- Do not invent testimonials, numbers, clients or awards.

## Known gaps

- The contact form has no backend. It builds the inquiry text and copies it to the clipboard. It needs a real email address or form service once the owner provides one.
- `img/logo.png` is a cut-out made from a low-resolution JPG and only works on dark backgrounds. Replace it with the original vector logo if one becomes available.
- `img/open-living.webp` (homepage hero) is only 1250px wide.

## Skills and plugins

Project skills live in `.claude/skills/` (gitignored) and are pinned in `skills-lock.json`:

- `impeccable`: design direction, critique, polish.
- `no-ai-design-slop`: quality gate while editing UI.
- `audit-ai-design-slop`: evidence-based design audit (report only).
- `design-taste-frontend`: anti-template reference. Its page plans and random "deal" scripts do not fit this site. Use it as reference only.
- `threejs-fundamentals`, `threejs-animation`, `threejs-materials`, `threejs-interaction`: three.js reference for the hero scene.
- `webgl-3d-object`, `build-awwwards-quality-sites`: 3D and motion-led art direction.
- `gsap-framer-scroll-animation`: ScrollTrigger recipes. `animation-vocabulary`: names for motion effects.
- `find-skills`: search and install more skills.
